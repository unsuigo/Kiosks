# Разрешение на работу с файлами проекта

Пользователь предоставляет Codex полный доступ ко всем файлам данного проекта. Codex может без дополнительных запросов на разрешение создавать, читать, изменять, перемещать и удалять файлы внутри проекта, если это требуется для выполнения поставленных задач.

Для любых изменений внутри проекта отдельное разрешение запрашивать не нужно.

Если необходимы изменения файлов или данных за пределами проекта, Codex предварительно запрашивает разрешение пользователя.
