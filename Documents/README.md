# Документация проекта

Эта папка содержит рабочую документацию по проекту выставочного киоска.

Документы должны описывать не только реализацию в Unity, но и продуктовые сценарии, оборудование, внешние интеграции, эксплуатацию на площадке и принятые архитектурные решения.

## Содержание

- [Постановка задачи](ProjectBrief.md) — назначение проекта, исходные требования и открытые вопросы.

## Планируемые разделы

По мере развития проекта здесь появятся:

- требования и пользовательские сценарии;
- описание оборудования и протоколов взаимодействия;
- архитектура приложения;
- интеграция с билетной системой;
- безопасность и работа с персональными данными;
- офлайн-режим и восстановление после сбоев;
- сборка, установка и обновление киоска;
- тест-план и чек-лист подготовки к выставке;
- журнал архитектурных решений.
